Why v2 exists. The audit found: phase work always on general-purpose agents; validate-story / qa-e2e / checkpoint-preview never run anywhere; one project with ~30 stories marked done and zero story files on disk. Every violated rule was prose. Prose doesn't survive a 40-agent session — scripts do.

Architecture

Every spawn passes through the hook. Typed agents do phase work; the ledger is the single audit trail.

The story cycle, enforced

The audit's worst finding — ~30 stories "done" with no story file — is now structurally impossible without a recorded user waiver.

Layer 1 — gate.py, the phase-gate ledger

Required gates (prd, architecture, epics, readiness, sprint) are verified against artifacts on disk — not against the model's memory of having run them.

python3 gate.py status                       # ✓ done / ~ skipped: reason / ✗ MISSING (exit 1)
python3 gate.py check story-validated 2-4    # precondition before spawning dev
python3 gate.py skip readiness --reason '…'  # deliberate skip, recorded
python3 gate.py waive epic-batch-dev --reason 'Tal approved in chat'
python3 gate.py decide party-mode skip --reason 'architecture uncontested'
The rule: run the step, or record the skip. There is no third option — and "the task didn't seem to need it" is a valid reason once it's written down.

Layer 2 — the spawn hook

hooks/bmad-agent-gate.py, registered as a PreToolUse hook on Agent|Task. Runs before any subagent exists:

Spawn shapeResult
BMAD phase work (bmad-dev-story, bmad-code-review, bmad-prd, …) on general-purpose / ExploreBLOCKED — message names the correct typed agent
bmad-dev-story with no story file on disk, none in the prompt, no waiver in the ledgerBLOCKED — "run create-story first, or record a waiver"
Typed agent + story file referenced and presentpasses
Any spawn outside a _bmad project, or any internal hook errorpasses (fail-open, zero cost)

Exit 2 stops the call and feeds the reason back — the model fixes the cause instead of rephrasing past the gate.

Layer 3 — optionals: judgment, recorded

CapabilityTrigger to consider it
bmad-party-modeContested decision, ≥2 defensible options, undecided user — multi-persona debate beats a wrong pick.
bmad-market-researchGreenfield product for external users, or "is there demand / who competes".
bmad-domain-researchUnfamiliar regulated or jargon-heavy domain.
bmad-prfaqUser genuinely unsure of the concept and open to being swayed.
bmad-advanced-elicitationA required-gate artifact feels shallow before committing — red-team it first.
bmad-specMessy multi-source intent that needs distilling before a PRD.
bmad-quick-devOne-off change outside any epic. Never inside a sprint.
bmad-customizeThe same skip keeps recurring — encode the fix into the workflow.

When a trigger fires, the call goes into the ledger with gate.py decide — one line. Skipping becomes a decision, not a blind spot.
